# 猫咪生活报
一个复古报刊风格，集每日计划、待办、习惯打卡、记账、长期目标和思考记录于一体的个人效率工作台。

## 在线体验
https://dinglin1017-ship-it.github.io/cat-live-report/

## 功能
- 🕒 今日节奏：实时时钟，展示当日日期与周次
- 📋 今日聚焦：快速记录待办事项
- ✅ 习惯与待办：任务清单，完成状态管理
- 📊 今日概览：可视化统计当日任务、打卡、阅读、运动进度
- 💰 猫咪账本：记录收支，统计本月结余
- 💡 灵感收藏：随手保存想法素材
- 📖 在读好书：管理阅读清单
- 🧠 洞察复盘：每日总结思考
- 💾 LocalStorage 本地自动保存，刷新页面数据不丢失

## 技术栈
- HTML
- CSS
- JavaScript

## 使用说明
1. 打开网页即可直接使用，无需注册登录
2. 所有数据保存在浏览器本地，清除浏览器数据会丢失记录
3. 支持在电脑端浏览器打开使用
